# キャラ8人と能力（M3 の後半）の設計書

- 日付: 2026-10-22
- 全体の設計書: `docs/superpowers/specs/2026-10-13-race-game-design.md`（5 キャラクター、10 CPU）
- この設計書は、全体の設計書の 5章を具体化したもの。顔ぶれ・能力の表・見た目の特徴は、5章のとおり（2026-10-22 のユーザーの判断「このままでOK」）。
- M3 の前半（アイテム）は `docs/superpowers/specs/2026-10-22-items-design.md`。main 522d1bc でできている。

## 1. 目的と前提

- 子どもが8人の中から好きなキャラを選んで走れるようにする。キャラによって走り方が少しちがう。
- CPU も8人のキャラになり、だれと走っているかが分かる。
- 対戦（M4）でも同じキャラのデータを使えるようにする。
- 動物たちはオリジナル。任天堂のキャラはまねない。

## 2. 8人と能力

能力は3種類、1〜5の5段階（全体の設計書 5.1）。

| タイプ | キャラ | 加速 | 最高速 | ハンドル | ジャンプの声 |
|---|---|---|---|---|---|
| 万能 | Kyugo | 3 | 3 | 3 | 男の子 |
| 万能 | Soki | 3 | 3 | 3 | 男の子 |
| 万能 | Penguin-man | 3 | 3 | 3 | 男の子 |
| スタートダッシュ | Rabbit Girl | 5 | 2 | 3 | 女の子 |
| スタートダッシュ | Mouse Boy | 5 | 2 | 3 | 男の子 |
| 最高速度 | Big Tiger | 2 | 5 | 2 | 男の子 |
| 最高速度 | Rampage Elephant | 2 | 5 | 2 | 男の子 |
| コントロール重視 | Lightning Cat | 3 | 2 | 5 | 女の子 |

- 8人のデータ（名前・能力・見た目・カートの色・声）は `src/data/characters.js` にまとめる。今の `src/main.js` の `PLAYER_CHARS`（選べる2人）と `CPU_LOOKS`（CPU の見た目）は、これに置きかえる。
- 能力の数字を実際の速さに直す表は、今の `src/game/stats.js`（`kartParams`）を使う。調整するのはこの表だけ。

### 2.1 能力の効き方

- 最高速: いちばん速いときの速さ（36〜46 m/s）。キノコ・加速板・Star の速さは、この何倍か。甲羅の速さは「使ったキャラの最高速の2倍」のまま。
- 加速: スピードに乗る速さ（11〜19 m/s²）と、スタートダッシュの長さ（今の `startDash` の加速の数字）。
- ハンドル: 曲がりやすさ（0.85〜1.16 rad/s）。ドリフトの曲がり方にも効く（今の `turnRate`）。
- TIME TRIAL も、選んだキャラの能力で走る。記録の表には、今と同じくキャラの名前を残す。

## 3. キャラ選びの画面と顔のアイコン

- 「Choose your racer」で8人を、横4人×2段に並べる。スマホの横向きでも1画面に収める。
- ボタンは、顔のアイコンと名前。能力（点や数字）は出さない（2026-10-22 のユーザーの判断）。ボタンの色は、そのキャラのカートの色。
- 前に選んだキャラは、次に開いたときにふちを光らせる（Level 選びと同じ）。
- 新しい6人の顔のアイコンを、今の Kyugo・Soki と同じ平らな絵（SVG。`src/titleArt.js` の `faceSvg`）で作る。キャラ選び・上位3人・結果の表・大会の順位で使う。
- タイトルの絵は、今のまま Kyugo と Soki の2人。
- 名前が KYUGO・SOKI のときの「1日15分まで」は、どのキャラを選んでも今のとおり。

## 4. 新しい6人の 3D の見た目

どのキャラも、今の Kyugo・Soki と同じ作り方（丸い大きめの頭のちびキャラを、球・円柱・円すい・箱で組み立てる。カートに乗ってハンドルを握る）。

| キャラ | 体 | 一目で分かる特徴 | カートの色 |
|---|---|---|---|
| Penguin-man | 黒い体・白いおなか | 頭のツンツンの毛、黒いサングラス（白い2本線の光）、黄色いくちばしと足、茶色のリュック（`docs/reference/penguin-man.webp` のとおり） | 水色 |
| Rabbit Girl | 白いうさぎ | 長い耳、赤いリボン | ピンク |
| Mouse Boy | 灰色のねずみ | 大きな丸い耳、細いしっぽ | 緑 |
| Big Tiger | オレンジの虎 | 黒いしま模様、丸い耳 | オレンジ |
| Rampage Elephant | 灰色のぞう | 長い鼻、大きな耳、ほかより大きな体（見た目だけ。当たる大きさは同じ） | 紫 |
| Lightning Cat | 黒ねこ | とがった耳、稲妻もようの黄色いスカーフ | 黄色 |

- カートの色は8人で重ならない（Kyugo は赤 `#c11f0a`、Soki は青 `#1c3c88` のまま）。
- 1人作るたびに、アプリ内ブラウザで前と後ろから見てスクリーンショットをユーザーに見せ、直す所を聞く。
- 動かない部品は1つにまとめる（今の `mergeStatic`）。描く回数を増やさない。
- 夜のステージのライト（`userData.lights`）、名前の札、星（転がったとき）など、今のキャラにある部品は新しいキャラにも付ける。

## 5. 大会の CPU

- 大会の最初に、自分が選ばなかった7人から4人をランダムに選び、その大会の5レースは同じ顔ぶれ（2026-10-22 のユーザーの判断「A」）。
- 名前の札・上位3人・結果の表・大会の順位には、キャラの名前（例: `Big Tiger`）を出す。今の `CPU1`〜`CPU4` はなくなる。
- スタートの並び（前のレースで勝った車ほど後ろ）は今のまま。
- CPU の速さ: そのキャラの能力に、今のレベル（1〜3、`cpuParams`）と、プレイヤーとの差で速さを少し変える仕組み（`rubberFactor`）をかける。
- 最高速5の CPU が強くなりすぎないこと: Level 2 で、どのキャラの CPU も、3・3・3 の車と1周の時間が大きく離れない（目安 ±8% 以内）。離れるときは `stats.js` の数字で調整する。

## 6. ファイル構成

- `src/data/characters.js`（新しく）: 8人のデータ（id・名前・能力・見た目・カートの色・声）と、大会の CPU を選ぶ関数。
- `src/game/stats.js`（今あるもの）: 能力の数字 → 速さ（そのまま。調整するときだけ直す）。
- `src/render/models.js`（今あるもの）: 新しい6人の 3D の形（`CHARACTERS` に足す）。大きくなるときは `src/render/characters/` に分ける。
- `src/titleArt.js`（今あるもの）: 新しい6人の顔のアイコン。
- `src/screens.js` `style.css`（今あるもの）: キャラ選びを8人に。
- `src/main.js`（今あるもの）: キャラのデータを `src/data/characters.js` から読む。自分と CPU の能力。大会の CPU。
- `src/game/cup.js`（今あるもの）: 大会の CPU の顔ぶれを覚える。

## 7. 確かめ方

- 自動テスト（`node --test`）:
  - 8人のデータがそろっている（名前・能力1〜5・カートの色・声）。カートの色が重ならない。
  - 能力の数字どおりに、最高速・加速・曲がり方が変わる（最高速5は3より速い、など）。
  - 大会の CPU は自分とかぶらない4人で、5レースとも同じ。
  - 8人のどのキャラの CPU も、5コースとも最後まで走れる。Level 2 で1周の時間が目安の中。
  - 新しい6人の 3D の形が作れる。動かない部品をまとめたあとの描く回数が、Kyugo・Soki と同じくらい。
  - 新しい6人の顔のアイコンがある。
- ブラウザで、6人の見た目を1人ずつ前と後ろから見る。キャラ選びの画面を、スマホの大きさでも見る。
- 公開して、タブレットで遊んでもらう。
