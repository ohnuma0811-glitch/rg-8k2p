## 1. 目的

- Soki（6歳）が考えた「ブリッジと森」のコースを作る。いちばんのこだわりは、下の道の上を渡る大きな石の橋（2026-10-16 のユーザー依頼）。
- 空想の森で、明るい昼の森（2026-10-16 のユーザーの判断）。オフロード（土の道）で、道が上下に波打つ。
- 道が分かれて、どの道を通るか選べる。川をジャンプで2回飛び越える。
- 走りの決まりは今のコースと同じ（3周、CPU 4台、ドリフト、加速板）。このコースならではの仕掛けは、イノシシとサル。

### 成功の基準

1. Soki が「ぼくの描いたコースだ」と分かる（橋、3本の道、川のジャンプ2つ、大きな丘、滝）。
2. 6歳の Soki がボタン操作で3周を走りきれる（ジャンプは必ず向こう岸に着き、坂やでこぼこでも止まらない）。
3. 安い Android タブレットでも、レース中に30fps以上を保つ（ほかのコースと同じ）。

## 3. コースの形

下書きのコースマップのとおり。上から見て、森のまわりを回る形。走る向き:

1. スタート（コースの右下）から、下の道を西へ。
2. ジャンプ①: 南から流れてくる川を飛び越える。
3. 左下で2本に分かれる: 外の道と真ん中の道。どちらも北へ。
4. 真ん中の道をしばらく北へ進んだ所で、内の道が分かれる（2026-10-16 のユーザー依頼）。
5. 外の道と真ん中の道は、左上（合流①）で1本になり、上の道を東へ。
6. 上の道は坂を上り、石のアーチ橋を西から東へ渡る。内の道は、その橋の下をくぐる（2026-10-16 のユーザー依頼「外側から東に向かう道が橋を渡り、一番の近道は橋の下をくぐる」）。
7. 内の道は橋の下をくぐったあと、右上へふくらんで、上の道と1本になる（合流②）。
8. 大きな丘（右上）を越える。
9. 右がわを南へ下りる。左手（コースの外、東）に滝。
10. ジャンプ②: 森の中から流れてくる川を飛び越える。滝の水も、ここで川に合流する。
11. スタートへもどって1周。

- 1周 約2.5km（いちばん長い外の道で）。万能タイプで1周 約1分。
- 道幅は 24m（ほかのコースと同じ）。分かれ道の3本は少し細くしてよい（一番細くて 18m）。
- 道の外（柵の内側の、道でない所）は、草ややぶ。今のダートと同じで遅くなる。柵の外には出られない。
- 道のふちは丸太の柵。

### 3.1 3本の道の違い（2026-10-16 にユーザーが OK）

| 道 | 長さ | 特徴 |
|---|---|---|
| 外の道 | いちばん長い | 上下にでこぼこ。加速板がある。そのあと橋を渡る |
| 真ん中の道 | 中くらい | 上下にでこぼこ。そのあと橋を渡る |
| 内の道（近道） | いちばん短い | 道ばたの木にサルがいて、木の実を投げてくる。橋の下をくぐる |

- 「近道は危ない」（2026-10-16 のユーザーの判断）。
- CPU は、分かれる所ごとに、3本の道を同じ確率（3分の1ずつ）で、周ごとにランダムに選ぶ（2026-10-16 のユーザー依頼）。左下で外の道か真ん中の道かを選び、真ん中の道を選んだ CPU は、内の道が分かれる所でさらに選ぶ（3本それぞれ3分の1になるように: 左下で外 1/3・真ん中 2/3、内の道の分かれる所で内 1/2・真ん中 1/2）。

### 3.2 道の高さ（上下に波打つ）

- オフロードなので、道を上下に波打たせる（2026-10-16 のユーザー依頼）。大小さまざまな坂を組み合わせ、見どころに大きな丘を置く（2026-10-16 のユーザー依頼「大きな丘を見どころに2個ほど」）。
- 大きな丘は2つ: 右上の「大きな丘」（高さ 約8m）と、橋へ上る坂（上の道。橋の上で 約8m）。
- 外の道と真ん中の道は「上下でこぼこ」: 高さ 1〜2m の小さな上り下りが続く。
- ほかの所は、高さ 2〜4m の中くらいの上り下り。
- スタートとゴールの前後（約 100m）は平らにする（スタートの並びとカメラが変にならないように）。
- 坂のふもとと頂上は、なめらかにつなぐ。坂の頂上を速く越えると、少しふわっと浮く。坂を上ると少し遅く、下ると少し速くなる。
- 道のまわりの地面も、道の高さに合わせてなだらかに上げ下げする。木や景色は、その地面の上に立てる（宙に浮いたり埋まったりしないように）。

### 3.3 橋（立体交差）

- 上の道が、石のアーチ橋で内の道の上を渡る。橋の上の道は、内の道から 約8m 上。
- 橋: 灰色の石を積んだ太い橋。下にアーチがいくつも並ぶ。上の道はゆるやかにカーブしながら渡る。橋の上の道は石の舗装、ふちに石の手すり。
- 内の道からは、頭の上をアーチの橋が通るのが見える。
- 車が上と下のどちらの道にいるかは、車の高さで決める。

### 3.4 ジャンプ2つ

- ジャンプ①（下の道）とジャンプ②（右がわの道）。どちらも、手前に加速板とジャンプ台を置き、川を飛び越える。
- Kenta Circuit のジャンプ台と同じで、飛び出す速さはいつも同じ。遅くても必ず向こう岸に着く（6歳の Soki でも落ちない）。

## 4. 景色

- 外周（コースの外側）は、基本的にジャングル（濃い緑の木。Kampar Town と同じ。2026-10-16 のユーザー依頼）。
- 森の中（コースに囲まれた所）は、絵の木のような、丸いかたまりを重ねたブロッコリーのような木を、びっしり並べる。
- 看板の文字は「Soki Forest」のように、小文字もまぜる（2026-10-16 のユーザー依頼）。森の名前の看板（「ブリッジと森」）は置かない（2026-10-16 のユーザー依頼）。

### 4.1 見どころ

1. 石のアーチ橋（3.3）。いちばんの見どころ。
2. 川: 南から流れてきて下の道の下を通り（ジャンプ①）、森の中を東へ流れ、右がわの道の下を通って（ジャンプ②）、東へ流れていく。青い水、両岸に石と草。
3. 滝: ジャンプ②の手前、右がわの道の外（東）に、がけと滝。滝の水は道に沿って流れ落ち、ジャンプ②の所で川に合流する。走りながら左手に見える。滝のしぶきは白い霧（2026-10-16 のユーザー依頼）。
4. スタートの門: 丸太で組んだ門に「Soki Forest」の看板。
5. 大きな丘の頂上: 1本の大きな木と、見晴らしの柵。
6. きのこと岩の広場: スタートの右下（絵の、点のある四角の所）。大きな赤い水玉のきのこと岩。
7. 道ばた: 花、切り株、草のしげみを、ところどころに。

## 5. 仕掛け（2026-10-16 にユーザーが OK）

### 5.1 イノシシ（3頭）

- 全員が通る道に出す: 下の道（スタートとジャンプ①の間）に2頭、上の道（合流②と大きな丘の間）に1頭。
- ふだんは道ばたのしげみにかくれていて、ときどき（8〜12秒に1回くらい。イノシシごとにずらす）、すばやく道を横切る（約2秒で渡りきる）。動きは時刻で決まる（牛と同じ）。
- 飛び出す少し前に、しげみがガサガサゆれて「ブヒッ」と鳴る（よけられるように）。
- ぶつかったとき: 牛と同じ。メーター150以上ならスピン、それより遅いと跳ね返る。ドリフトは解除される（ミニターボなし）。
- CPU は、牛と同じように、よけたりスピードを落としたりする。

### 5.2 サル（3匹、内の道だけ）

- 内の道の道ばたの高い木の上にいる。
- 車が近づくと（約40m）、その車が少し先で通る所をねらって木の実を投げる。1匹が 約3秒に1回。
- 木の実が落ちる所に、約1秒前から丸い影が出る。投げるとき「キキッ」と鳴く。
- 当たったとき: 速さに関係なくスピン。「コツン」と鳴る。ドリフトは解除される（ミニターボなし）。外れた木の実は、地面に落ちて消える。
- CPU は、影が見えたら、よける。

## 6. 作り方

- Kampar Town と同じ作り方: 景色は「どこに何を置くか」の一覧（データ）と、森用の部品（ブロッコリーの木・きのこ・切り株・岩・丸太の柵・丸太の門・石の橋・滝など）で作る。すき間の森は自動で埋める（Kampar Town のジャングルと同じ）（2026-10-16 にユーザーが OK）。
- ゲームの仕組みを、次のように広げる（ほかのコースの動きは変えない）:
  - 分かれ道: コースを「本線」と「分かれ道」で作る。本線は、スタート → 下の道 → 外の道 → 上の道 → 橋 → 大きな丘 → ジャンプ② → スタート。分かれ道は、真ん中の道と内の道。
    - 車がどこにいるか: 本線と分かれ道の両方から、いちばん近い道を探す（橋の所は高さも見る）。
    - 順位と周回: どの道を通っても、本線の上の同じ場所に置きかえて数える（近道で前に出れば順位も上がる）。1周はスタートの線を越えたときに数える。
    - ミニマップ: 分かれ道も描く。
  - 道の高さ: 道の場所ごとの高さ（3.2）と、それに合わせた地面。
  - ジャンプ: 1つのコースに2つ置けるようにする（今は1つだけ）。
- 森の曲を新しく作る: 明るくて、木の楽器ふうの、はずむ曲（コースごとに別の曲）。
- 大会は3レース（Kenta Circuit → Kampar Town → Soki Forest）。
- 確かめ用: URL の後ろに `#course3` を付けると、1レース目から Soki Forest。
- 作業はブランチ `soki` で行い、できたら main へまとめる。

## 7. 確かめ方

- テスト: 分かれ道のどれを通っても3周が数えられる、順位が正しい、CPU が3本の道をだいたい同じ回数選ぶ、橋の上と下で車の場所が正しく分かる、ジャンプ2つで必ず向こう岸に着く、イノシシ・木の実でスピンする、景色が道の上に立たない、など。
- ブラウザで、上から見た形がコースマップと合うか、橋・滝・丘の見え方、スマホでの速さ（30fps 以上）を確かめる。
- できたところから公開して、ユーザーにスマホで走ってもらう。
