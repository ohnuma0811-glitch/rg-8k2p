## 1. 目的と範囲

- GAME CODE で入った人が、同じ1つの待合室に集まり、だれがいるかが分かり、チャットで声をかけ合える。
- 全員が READY を押したら、コースの投票（10秒）をして、走るコースを決めるところまで作る（2026-10-22 のユーザーの判断）。
- M4-B に入れないもの（M4-C）: コースが決まったあとのスタートの合図、5台に足りない分の CPU と、CPU を受け持つ端末の決め方（性能を測る）、レース中の位置の送り合い、結果のあと待合室に戻ること。M4-B では、コースが決まったら「The race is coming soon.」と出して、待合室に戻る（全員の READY を外す）。

## 2. 流れ

- タイトル → VS RACE → GAME CODE（入った端末は飛ばす）→ 名前 → キャラ選び（SOLO と同じ8人の画面）→ 待合室。
- 待合室の BACK でタイトルへ（待合室から出る）。
- 待合室にいる間は、遊べる時間に数えない。
- 待合室にいる間に GM がコードを変えたり止めたりしたら、「The game code was changed.」と出して、GAME CODE の画面に戻る（`/status` の `codeId`・`active` を見る）。
- BATTLE を選んだときは、今のまま（GAME CODE → 名前 →「coming soon」）。

### 2.1 READY とコースの投票（2026-10-22 のユーザーの判断）

- 待合室にいる人は、全員走る前提。START ボタンも CANCEL ボタンも作らない（だれでも押せる START と CANCEL は、子どもが混乱するため）。
- 待合室の自分の行の横に、大きな「READY」ボタン。押すと「READY ✓」、もう一度押すと取り消し。一覧で、だれが READY か分かる。
- 待合室の全員（2人以上）が READY になったら、全員の画面にコースの投票の画面を10秒出す。
  - 5つのコース（絵と名前）と、残りの秒数。押したコースに、その人の1票。10秒の間は、押し直して変えられる（最後に押したもの）。
  - 押されている数を、コースごとに顔で見せる（だれがどこを選んでいるか分かる）。
  - 10秒の間に押さなかった人は、投票しなかったことにする。レースには参加する。
  - いちばん多く選ばれたコースに決まる。同じ数なら、そのコースの中からランダム。だれも選ばなかったら、5つのコースからランダム。ランダムは、全員の端末で同じ結果になる（投票ごとに決めた数をもとにする）。
  - 決まったら「Kampar Town — 3 players picked!」（日本語を選んでいる人には「Kampar Town — 3人がえらびました！」）を2秒出す（言語は定型文と同じ設定）。
- 走る人は、投票が始まったときに待合室にいる人。投票の途中で入ってきた人は、待合室で待ち、次のレースから参加する。
- 投票の途中で、走る人のだれかが待合室から出たら（アプリを閉じた・電波が切れた）、その人を外して投票を続ける。走る人が1人になったら、投票をやめて待合室に戻る。

## 3. サーバーのデータと守りの決まり（ルールに足す）

「今のコードで入った端末」（以下「入っている端末」）: `root.child('access/' + auth.uid + '/codeId').val() === root.child('secret/codeId').val() && root.child('secret/active').val() === true`。

| 場所 | 中身 | 読める・書ける人 |
|---|---|---|
| `/lobby/{uid}` | `name`（`^[A-Z]{1,12}$`）、`char`（キャラの id）、`codeId`（今のコードの番号）、`at`（時刻） | 入っている端末だけが `/lobby` を読む。自分の分だけ書く・消す。GM も読める |
| `/chat/{codeId}/{pushId}` | `uid`、`name`、`char`、`preset`（定型文の番号 0〜12）か `text`（1〜100文字）のどちらか1つ、`at`（サーバーの時刻） | 入っている端末だけが今のコードの `/chat/{codeId}` を読む。送れるのは `uid` が自分で、`codeId` が今のコードのとき。書き直し・自分での削除はできない（新しく足すだけ）。GM は読む・消す |
| `/chatLast/{uid}` | 最後に送った時刻（サーバーの時刻） | 自分だけ書く。前の値から1秒（1000ミリ秒）以上たっていないと書けない |
| `/lobby/{uid}/ready` | READY か（true / false） | 自分だけ |
| `/room` | `phase`（`lobby` / `voting` / `decided`。M4-C で `racing` を足す）、`voteId`（投票ごとの番号）、`endsAt`（投票が終わるサーバーの時刻）、`racers`（走る人の uid の一覧）、`seed`（同じ数のときのランダムのもと）、`course`（決まったコースの番号） | 入っている端末が読む・書く（下のとおり、決まった順にだけ変えられる）。GM も |
| `/room/votes/{uid}` | 選んだコースの番号（0〜4） | `racers` に入っている人が、自分の分だけ。`phase` が `voting` で、`endsAt` より前のときだけ |

- 送るとき: `/chat/{codeId}/{pushId}` と `/chatLast/{uid}` を1回で書く（複数の場所を一度に）。メッセージの `at` と `chatLast` は、どちらもサーバーの時刻（`now`）でなければならない。ルールで `chatLast` が1秒たっていないと断るので、メッセージも書けない（1秒に1回まで）。
- 待合室から消える: 入ったときに `onDisconnect().remove()` を `/lobby/{uid}` にしかける（アプリを閉じた・電波が切れたら、Firebase のサーバーが消す）。BACK で出るときは自分で消す。
- だれもいない待合室に入るとき: 入っている端末は、`/lobby` に1人もいない（`!root.child('lobby').exists()`）ときだけ、`/chat/{今の codeId}` をまとめて消せる。そのあとで自分の `/lobby/{uid}` を書く（2026-10-22 のユーザー依頼「全員退室したら全部消す」。最後の人が出るときではなく、だれもいない待合室に最初の人が入るときに消す。見た目は同じ）。
- 新しいコード（GM の Set）: 古いコードの `/chat/{古い codeId}` を一緒に消す。待合室にいた人は、コードが変わったので GAME CODE の画面に戻る（`/lobby` の自分の分を消してから）。
- GM: メッセージを1件ずつ、または今のコードの分を全部消せる。`/lobby` を読める。
- 画面に出すのは、今のコードの最新の50件（`limitToLast(50)`）。古いものはサーバーに残るが、文字だけなので量は小さい。
- 部屋の状態の変え方（どの端末がしてもよい。同時にしても1回になるよう、Firebase の transaction で `phase` を見てから変える）:
  - `lobby` → `voting`: 待合室の全員（2人以上）が READY になったのを見た端末が、`voteId`・`endsAt`（今のサーバーの時刻＋10秒）・`racers`（そのときの待合室の全員）・`seed` を書く。
  - `voting` → `decided`: `endsAt` を過ぎたのを見た端末が、票を数えて `course` を書く。全員の端末が同じ数え方・同じ `seed` なので、だれが書いても同じ結果。
  - `voting` → `lobby`: 走る人が1人になったら（2.1）。
  - `decided` → `lobby`: M4-B では、2秒の知らせのあと。全員の READY を外し、`votes` を消す（M4-C では `racing` へ進む）。
- 待合室の全員が出て、だれもいなくなったときは、次に最初に入った端末が `/room` を `lobby` に戻す（チャットを消すのと一緒に）。

## 4. 待合室の画面

- 横向きのスマホで1画面に収める。
- 上の段: ◀ BACK、キャラの選び直し（キャラ選びの画面へ行って、待合室に戻る）、歯車。
  - 歯車: 音の ON/OFF、操作の切り替え（ボタン / キーボード）、定型文の言語（English / 日本語）。
- READY: 2.1 のとおり。1人のときは押せるが、2人以上そろうまで投票は始まらない（「Waiting for players…」）。
- 左がわ: 入っている人の一覧（キャラの顔・名前）。自分の行は黄色。人数（「3 players」）。
- 右がわ: チャット。
  - 上はメッセージの一覧（新しいものが下）。各行に、送った人の顔・名前・文。自分の文は右寄せ。新しいメッセージが来たら、いちばん下まで送り、小さな音を鳴らす（自分の文のときは鳴らさない）。
  - 下は、定型文のボタン（横に並べ、指で横にずらして選ぶ。「Press READY!」が先頭、その次に通話の2つ）と、自由な文を打つ欄と「Send」。
- 自由な文: スマホのキーボードで打つ。前とうしろの空白を取り、空なら送らない。100文字を超えた分は打てない（`maxlength`）。翻訳しない。
- 送るのが早すぎた（1秒以内）ときは、ボタンを少しの間おせなくするだけ（文は消さない）。
- 文字は英語。定型文だけ、読む人の言語で出す。

## 5. 定型文と言語

- 定型文（13個。番号 0〜12。この順。全体の設計書 2.1 の表から「Don't press START yet!」を外し、いちばん使う「Press READY!」をいちばん押しやすい先頭に。2026-10-22 のユーザー依頼）:

| 番号 | English | 日本語 |
|---|---|---|
| 0 | Press READY! | READYを おして！ |
| 1 | Let's call on LINE! | LINEを つなごうよ！ |
| 2 | Let's call on WhatsApp! | WhatsAppを つなごうよ！ |
| 3 | Hello! | こんにちは！ |
| 4 | Ready? | じゅんび できた？ |
| 5 | Let's go! | いくよ！ |
| 6 | Wait a sec! | ちょっと まって！ |
| 7 | One more! | もう いっかい！ |
| 8 | Good game! | いいしょうぶだった！ |
| 9 | Nice! | ナイス！ |
| 10 | So close! | おしい！ |
| 11 | I'll win next time! | つぎは まけないよ！ |
| 12 | Bye! | またね！ |

- 送るのは番号だけ。受け取った端末が、その人の言語の文にして出す。
- 言語: 最初は端末の言語（`navigator.language` が `ja` で始まれば日本語、それ以外は English）。待合室の歯車で変えられ、その端末で覚えておく（言語を選ぶ画面は作らない。2026-10-22 のユーザーの判断）。

## 6. GM 画面に足すもの

- 「Chat」: 今のコードのメッセージの一覧（新しい順、名前・文・時刻）。1件ずつ「Delete」、全部を「Delete all」。
- 「Lobby」: 今、待合室にいる人の名前とキャラ。
- Set（新しいコード）のとき、古いコードのチャットも一緒に消す。

## 8. 確かめ方

- `node --test`: 票の数え方（いちばん多い・同じ数ならその中からランダム・だれも選ばなければ全部からランダム・同じ seed なら同じ結果）、全員 READY で投票が始まる・1人では始まらない、締め切りを過ぎたら決まる、走る人が1人になったら待合室に戻る、定型文（13個、先頭が Press READY!、番号 → 言語の文、端末の言語から最初の言語）、文の確かめ（空・空白だけ・100文字）、1秒に1回、最新50件、だれもいないときだけチャットを消す、入る・出る、コードが変わったら知らせる。
- ルールのテスト（Emulator）: 入っていない端末は `/lobby` `/chat` を読めない・書けない。ほかの人の `/lobby` は書けない。ほかの人の `uid` では送れない。前のコードの `/chat` には送れない。1秒たたないと送れない。書き直せない・消せない（だれかいるとき）。だれもいなければ消せる。GM は読む・消す。`preset` と `text` の両方は入れられない、101文字は入れられない。
- ブラウザで: 2つのタブで待合室に入り、両方が READY を押すと投票の画面になり、選んだコースが2つの画面で同じに決まり、知らせ（英語・日本語）が出る。一覧とチャットが行き来する。定型文が、それぞれの言語で出る。片方のタブを閉じると、もう片方の一覧から消える。全員出てから入り直すと、チャットが消えている。GM 画面でチャットを消せる、Lobby に出る。GM がコードを変えると、待合室の人が GAME CODE の画面に戻る。スマホの横向き（812×375）で1画面に収まる。
