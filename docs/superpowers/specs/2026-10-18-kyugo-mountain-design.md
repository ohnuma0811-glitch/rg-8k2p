## 1. 目的

- Kyugo が考えた雪山のコースを作る（2026-10-18 のユーザー依頼）。絵をもとにして、細かい所は調整する。
- 快晴の雪山。道は少しすべり、近道（A）には凍った所がある（2026-10-18 のユーザーの判断）。
- 道が A と B に分かれ、3か所の立体交差（橋）と、道を飛び越えるジャンプがある。
- 走りの決まりは今のコースと同じ（3周、CPU 4台、ドリフト、加速板、CPU の Level 1〜3）。このコースならではの仕掛けは、雪だるま・コブゾーン・スロー（逆向きの板）・凍った道・トンネル。

### 成功の基準

1. Kyugo が「ぼくの描いたコースだ」と分かる（観客席と川、A の輪とジャンプ、B のくねくね道とスロー、コブゾーン、トンネル、まわりの山）。
2. A と B のどちらを通っても、有利・不利の差が小さい（CPU の時間で確かめる）。
3. 6歳の Soki でも Level 1 で3周を走りきれる（ジャンプは必ず向こうに着き、坂や仕掛けで止まらない）。
4. 安い Android タブレットでも、レース中に30fps以上を保つ（ほかのコースと同じ）。

## 3. コースの形

下書きのコースマップのとおり。走る順番:

1. スタート（左の縦の道）から北へ。
2. 左上で右へ曲がる。左に観客席、曲がってすぐ左に川がよく見える。
3. 上の道を東へ。観客席を過ぎると、道がアスファルトから雪の山道に変わる。分かれ道まで上り坂。
4. 分かれ道で A と B に分かれる。
5. A と B は、コブゾーンの手前で合流する。
6. コブゾーンを通って、右の山のトンネルに入る。
7. トンネル（下のくねくねした長い道）を西へ抜けて、左下の山から出る。
8. スタートへ戻って1周。

- 1周 約2.5km（いちばん長い道で）。万能タイプで1周 約1分。
- 道幅は 24m（ほかのコースと同じ）。分かれ道は少し細くしてよい（一番細くて 20m）。
- CPU は、分かれ道で A と B を半分ずつ選ぶ（周ごとにランダム）。

### 3.1 A（近道）と B

| 道 | 通る所 | 特徴 |
|---|---|---|
| A（近道） | 分かれ道から東へ → 右上の大きな輪 → スピードアップ（加速板）→ ジャンプ台で上の道を飛び越えて南へ → コインのある横の道を東へ → 合流 | ゆるやかな下り坂。凍った所が3か所 |
| B | 分かれ道から右下へ → コインの所から右下へ急な下り坂 → 下のくねくね道を西へ → スローのある縦の道を北へ → スピードアップの横から輪の内がわ → 右下へ → 合流 | 急な下り坂。スローの板が3枚。合流の直前は急な上り坂 |

- コインは、今回は作らない（2026-10-18 のユーザー判断で保留）。
- どちらを通っても有利・不利の差が出ないように、加速板やじゃまもので調整する（2026-10-18 のユーザー依頼）。CPU の時間で確かめて、差が小さくなるようにする。

### 3.2 道が交わる所（2026-10-18 にユーザーと確認）

| | 上 | 下 |
|---|---|---|
| ① | A（ジャンプ台で飛び越える） | 分かれ道の手前の上の道 |
| ② | 分かれ道の手前の上の道（橋） | B（スローの縦の道） |
| ③ | A（コインのある横の道。橋） | B（右下への急な下り坂） |
| ④ | A（輪の左がわ。橋） | B（輪の内がわへ入る道） |

- 橋の上と下の道の高さの差は、7m 以上（Soki Forest の橋と同じ）。
- 車が上と下のどちらの道にいるかは、車の高さで決める（Soki Forest と同じ）。
- ① のジャンプは、Kenta Circuit のジャンプと同じく、飛び出す速さはいつも同じで、必ず向こう側に着く。

### 3.3 道の高さ（Soki Forest の2倍。2026-10-18 のユーザー依頼「山なので高低差を2倍に」）

- スタートと観客席のあたりは平ら（スタートの前後 約100m）。
- そこから分かれ道まで上り続け、分かれ道がいちばん高い所（約48m）。
- A はゆるやかに下る。輪の左がわは高く、ジャンプ台で上の道を飛び越える。③④では橋で B の上を通る。
- B は急に下り（約40m）、上の道・A の輪・A の横の道の3か所で下をくぐる。合流の直前は急な上り坂。
- コブゾーンとトンネルは、ほぼ平ら。トンネルを出てスタートに戻るまでに、低い所へ下りる。
- 坂のふもとと頂上は、なめらかにつなぐ。
- 急な上り坂で遅くなってスピード感がなくなる所には、加速板を置く（2026-10-18 のユーザー依頼）。
- 道のまわりの地面も、道の高さに合わせてなだらかに上げ下げする（Soki Forest と同じ）。

### 3.4 路面（2026-10-18 のユーザー依頼）

- スタートから観客席を過ぎるまでは、アスファルト（すべらない）。
- 観客席を過ぎてからは、雪の山道（少しすべる: ハンドルを切ってから曲がるのが少しおそく、外へふくらみやすい）。
- A には凍った所を3か所（長さ 約25m、道はばいっぱい）。雪の道よりもっとすべる。
- トンネルの中は、Kenta Circuit のような舗装の道（すべらない）。

## 4. 景色（2026-10-18 にユーザーが OK）

- 快晴の青い空。まわりはぜんぶ白い雪山（道よりずっと高い。100m 以上）。茶色い岩山の壁はやめた（2026-10-18 のユーザーの判断）。
- 地面は雪の白。道のふちは、雪の土手と低い木の柵。
- スタートの内がわの森は、雪のつもったとがった木（もみの木）。道ばたにもところどころ。
- スタートの門に「Kyugo Mountain」の看板（小文字もまぜる）。
- 観客席: スタートから右へ曲がった左がわ。Kenta Circuit の観客席を雪の色にしたもの。
- 川: 左上。右へ曲がるすぐ左に見える。水は青、両岸に雪と氷。
- 橋（②③④）: 石の橋に雪がつもった形。
- ジャンプ台: A のスピードアップの先。黄色と黒のしま（Kenta Circuit と同じ）。
- トンネル: 入口と出口は、雪山の岩はだに石のアーチの口。
- 凍った所は水色でつやのある道。スローの板は、うしろ向きの矢印が流れて見える板。コブゾーンは白い雪の丸いコブ。

## 5. 仕掛け（2026-10-18 にユーザーが OK）

### 5.1 雪だるま（15体）

- 顔（炭の目・にんじんの鼻）に、帽子とマフラー。ぴょんぴょん跳ねながら、道を左右に行ったり来たりする。
- ぶつかったとき: Kampar Town の牛と同じ。メーター150以上ならスピン、それより遅いと跳ね返る。ドリフトは解除される。ぶつかったあと 1.5秒は、雪だるまに押されずに通りぬけられる（Soki Forest のイノシシと同じ。はまって動けなくならないように）。
- 置く所（コース全体で15体。2026-10-18 のユーザー依頼）:
  - 共通の道に7体（観客席を過ぎた上り坂に4体、合流のあと〜コブゾーンの手前に1体、トンネルを出たあと〜スタートの手前に2体）。
  - A に4体、B に4体。
  - スタートの前後、コブゾーン、トンネルの中には置かない。
- CPU は、牛と同じようによけたり、スピードを落としたりする。

### 5.2 コブゾーン（トンネルの直前、約60m）

- 白い雪の丸いコブ（直径 約3m）を、10個くらい並べる。
- 正面から当たると、ぴょんと跳ねる。横から当たると、横へはじかれる。当たると「ぼよん」の音。

### 5.3 スロー（B の縦の道）

- 逆向きに動く歩く歩道のような板。長さ 約30m、はばは道の 約30%。乗っている間は前に進みにくい（うしろへ引っぱられる）。
- 道の左・右・左とずらして3枚。
- CPU は、なるべく板のない所を通る。

### 5.4 トンネル

- 入ると、一度画面が暗くなり、そのあとは暗いままになる。
- カートの前にライトがついて、前だけが明るく見える。画面のまわりは暗い（見える所がせまくなる）。
- 出ると、明るく戻る。

## 6. 音

- 雪山の新しい曲: 鈴（ベル）の音を入れた、明るくはずむ曲（コースごとに別の曲）。最後の周で少し速くなる。
- コブに当たると「ぼよん」。
- 雪だるまにぶつかると「ドン」（牛・イノシシと同じ）。近くで跳ねると小さな「ぴょん」。
- トンネルの中では、エンジンの音が少しこもる。

## 7. 作り方

- Soki Forest と同じ作り方: 分かれ道（本線と分かれ道）、道の高さ、橋、ジャンプ、地面、景色の一覧（データ）と部品、すき間の木の自動の置き方を使う。
- 新しく作るもの: 雪の見た目（地面・木・山・橋・観客席）、すべる道（雪・氷）、スローの板、雪だるま、コブゾーン、トンネル（形・暗さ・ライト）、雪山の曲。
- 大会は4レース（Kenta Circuit → Kampar Town → Soki Forest → Kyugo Mountain）。
- 確かめ用: URL の後ろに `#course4` を付けると、1レース目から Kyugo Mountain。
- 作業はブランチ `kyugo` で行い、できたら main へまとめる。

## 8. 確かめ方

- テスト: 3周を走りきれる、A でも B でも順位が正しい、A と B の時間の差が小さい、3つの橋の上と下で車の場所が正しく分かる、ジャンプで必ず向こう側に着く、雪だるま・コブ・スロー・凍った所が決めたとおりに動く、CPU が動けなくならない、など。
- ブラウザで、上から見た形が下書きのコースマップと合うか、橋・トンネル・雪の見え方、スマホとタブレットでの速さ（30fps 以上）を確かめる。
- できたところから公開して、ユーザーにスマホで走ってもらう。
