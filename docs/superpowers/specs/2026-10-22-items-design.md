# アイテム（M3 の前半）の設計書

- 日付: 2026-10-22
- 全体の設計書: `docs/superpowers/specs/2026-10-13-race-game-design.md`（9 アイテム、10 CPU、12 画面の表示、13 音）
- この設計書は、全体の設計書の 9 章を具体化したもの。ちがう所は、この設計書を正とし、全体の設計書も直す（「全体の設計書から変わる所」）。
- M3 は2つに分ける（2026-10-22 のユーザーの判断）。前半がアイテム（この設計書）、後半がキャラ8人と能力（あとで別の設計書）。

## 1. 目的と前提

- SOLO RACE を、アイテムでもっと楽しくする。子どもがすぐ分かり、「ずるい」と感じにくいこと。
- アイテムは5コースすべてで使う。TIME TRIAL には箱もアイテムもない。
- 今ある障害物（牛・バス・路面電車・タクシー・イノシシ・サル・雪だるま・恐竜など）はそのまま残す。
- M4（対戦）で使えるように、甲羅・バナナ・稲妻は「だれが・いつ・どこで・何を使ったか」という1回の出来事から、どの端末でも同じように動く形で作る。
- 絵は自分たちで描き、任天堂のデザインはまねない。名前は普通の英語（全体の設計書 9.1）。

## 2. 「?」の箱

- 道を横切るように、箱を横一列に並べる。数は道幅に合わせて4〜6個。
- 周回のあるコース（Kenta Circuit・Kampar Town・Soki Forest・Kyugo Mountain）: 1周に1列。コースの真ん中あたり。分かれ道があるコースは、どちらの道にも置く。Kenta Circuit はコースマップの左下、Kampar Town は真ん中あたりと ECONSAVE の横断幕の手前の2列、Soki Forest はコースマップの下（スタートのあとの直線）にも1列（2026-10-22 のユーザー依頼）。
- World Cities: 次の5か所に1列ずつ（全部で5列）。東京駅の周り・京都・富士山・海底・NY。自動の区間（大ジャンプ・宇宙・ワープなど）と、地面のない所には置かない。
- 取った箱は消え、2秒後に同じ場所に戻る。
- 枠にアイテムを持っているときに箱を取っても、新しいアイテムはもらえない（箱は消える）。

## 3. アイテム枠とルーレット

- 持てるアイテムは1つ（上の真ん中の枠）。
- 枠が空のときに箱を取ると、枠の中でルーレットが約2秒回り、「ピンピンピン」で決まる。ルーレットの間に ITEM を押すと、すぐ止まる。
- 何が出るかは、箱を取った瞬間の順位で決める（5章）。
- 緑の甲羅を体のまわりに回したとき、バナナを後ろにぶら下げたときは、枠は空として扱う。次の箱でアイテムを取れる。
- 緑の甲羅が体のまわりに1つでも残っている間は、枠の新しい緑の甲羅を回すことはできない（全部投げ終わってから）。

### 3.1 ITEM ボタンを押したときの順番

1. 後ろにバナナをぶら下げていれば、そのバナナをその場に置く。
2. なければ、体のまわりに緑の甲羅があれば、1つ前へ投げる。
3. どちらもなければ、枠のアイテムを使う（バナナはぶら下げる、緑の甲羅は回しはじめる）。

- 吹き飛んでいる間・転がっている間・自動の区間の間・ゴールしたあとは、使えない。

## 4. 6つのアイテム

### 4.1 Mushroom

- 1.5秒、加速板と同じ 1.3倍で走る。ダートでもおそくならない。
- 3個セット。ITEM を押すたびに1個ずつ使い、3回使える。使い切るまで枠はキノコのまま（残りの数のキノコの絵）。CPU は前のキノコの加速が終わってから次を使う（2026-10-22 のユーザー依頼）。

### 4.2 Banana

- 1回目の ITEM で、カートの後ろにぶら下げる。2回目の ITEM で、その場（車の 3m 後ろ）に置く。
- ぶら下げている間は、後ろから来る緑の甲羅・赤の甲羅を必ずふせぐ。ふせいだら、バナナも甲羅も消える。
- 置いたバナナは、踏まれるまで残る。コース全体で10個まで。超えたら古い物から消える。
- 踏んだ車は、5秒間ハンドルの左右が入れ替わる（6章）。スピンはしない。見た目と動きは Soki Forest のぬかるみと同じ（車から煙がもくもく出る）。

### 4.3 Shell（赤の甲羅）

- 狙う相手は、使った時点で自分のひとつ前の順位の車（人でも CPU でも）。飛んでいる間に順位が変わっても、相手は変わらない。
- 速さは、使ったキャラの最高速の2倍。道にそって相手を追いかけるので、カーブや交わる所でも壁に当たらない。
- 1位で使ったとき（前に車がいない）は、前にまっすぐ飛び、5秒で消える。
- 相手がゴールしたら消える。
- 当たった車は吹き飛ぶ（7章）。

### 4.4 Green Shell ×3（緑の甲羅）

- 1回目の ITEM で、3つが120度ずつ間をあけて体のまわりを回りだす。そのあと ITEM を押すたびに、1つずつ車の向いている方へまっすぐ飛ぶ。速さは最高速の2倍。相手は追いかけない。
- 柵に当たるとはね返る。3回まで。4回目に当たったら消える。投げてから5秒でも消える。
- 投げた直後の 0.5秒は自分に当たらない。そのあとは、はね返ってきた自分の甲羅にも当たる。
- 後ろには投げない（いつも前）。
- 当たった車は吹き飛ぶ（7章）。

### 4.5 Star

- 9秒、無敵（2026-10-22 のユーザー依頼で 6秒の 1.5倍）。
- 最高速は 1.4倍（2026-10-22 のユーザー依頼で 1.2倍から）、加速は2倍、ハンドルは少し曲がりやすく（数字で +1 くらい）。ダートでもおそくならない。
- カートとキャラが虹色にピカピカ光る。終わる1秒前から点滅する。
- 無敵の間だけ、明るい短いメロディをくり返す。鳴るのは無敵になった本人の端末だけ。ほかの人の画面では光るのが見えるが、BGM は変わらない（2026-10-22 のユーザー依頼）。
- ほかの車に当たると、相手が吹き飛ぶ（7章）。
- 牛・バス・イノシシ・雪だるまなどの障害物に当たっても、自分はスピンも転がりもしない。甲羅・バナナ・稲妻も効かない。壁にはふつうに当たる。

### 4.6 Lightning

- 自分以外の全員（CPU も）に稲妻が落ち、10秒間、ハンドルの左右が入れ替わる（6章）。Star の車には効かない。
- 落ちた瞬間、画面が一瞬白く光り、車に稲妻が見える。音は `sounds/Thunder-Synthetic01-1.mp3`。
- 入れ替わりの間は、画面の端が黄色く光る。車からは、ぬかるみと同じ煙が出る。

### 5.3 表の使い方

- 台数が8台より少ないときは、1位は「1位」の行、最下位は「8位」の行、間は表の中で同じ割合の位置の行を使う（行 = 1 + (順位 − 1) × 7 ÷ (台数 − 1) を四捨五入）。5台なら、1位→1位、2位→3位、3位→5位、4位→6位、5位→8位 の行。1台だけのときは1位の行。
- Lightning は、そのレースの実際の順位が下半分（下から「台数 ÷ 2 の切り捨て」台）のときだけ、表の数字で出る。8台なら5〜8位、6台なら4〜6位、5台なら4・5位、2台なら2位。下半分でないときは、Lightning の分を Mushroom に足す。人も CPU も同じ。
- 表は `src/game/itemOdds.js` にまとめ、遊んで調整する。

## 6. 左右の入れ替え（Banana と Lightning）

- Banana は踏んだ車だけに5秒、Lightning はほかの全員に10秒。ボタン・キーボードのどちらでも入れ替わる。
- 入れ替わっている最中にまた入れ替わりが起きたら、残りは「今の残り」と「新しい時間」の長い方にする（2回で元に戻ることはない）。
- 残りの秒数は出さない。
- CPU は、入れ替わっている間、ふらふらと走る（ぬかるみのときと同じ）。
- Star の車には効かない。
- 今ある `kart.muddy`（ぬかるみ）と同じ仕組みを使う。

## 7. 吹き飛ぶスピン

- 起きるとき: 赤・緑の甲羅に当たったとき、Star の車にぶつかられたとき。Banana ではスピンしない。
- 当たった瞬間に、小さな爆発（オレンジの光と煙の玉）。音は `sounds/Explosion04-1(Short).mp3`。
- キャラがカートごと約3m 上に飛び、空中で横に2回転して落ちてくる。全部で約1.5秒。その間はハンドルもアクセルも効かない。
- 着地したらスピード 0 から。向きは道の進む方向。落ちる場所は当たった場所（コースの外には飛ばさない）。
- 高さ・時間・回る回数は、遊んで調整する。
- 今ある牛などのスピン（その場で1秒回る）と、雪のコブで転がる動きは、そのまま。

## 8. 守り

- 体のまわりの緑の甲羅は、120度ずつ間をあけて回る。1つの甲羅は、自分のまわり120度ぶんの方向を受け持つ。
- 赤・緑の甲羅、置かれたバナナが、どの方向（前・横・後ろ）からぶつかってきても、その方向に自分の甲羅が回ってきていればふせぐ。ふせいだら、ぶつかってきた物と、回っていた甲羅が1つ消える。
- 結果として、3つなら必ず、2つなら約66%、1つなら約33% でふせぐ（サイコロではなく、甲羅の位置で決まる。2026-10-22 のユーザー依頼）。
- 後ろにぶら下げたバナナは、後ろから来る赤・緑の甲羅を必ずふせぐ（4.2）。

## 9. 甲羅の当たり

- 車・置かれたバナナ・回っている甲羅に当たる。置かれたバナナに当たったら、両方とも消える。
- Star の車に当たったら、甲羅だけが消える。
- 障害物（牛・バス・路面電車・タクシー・イノシシ・雪だるま・恐竜など）はすり抜ける（2026-10-22 のユーザー依頼）。
- ジャンプ台は越えられず、そこで消える。自動の区間に入ったときも消える。
- 自動の区間にいる車には、甲羅・バナナ・稲妻が効かない。その車はアイテムも使えない。

## 10. CPU

- CPU のアイテムは 5.2 の表で決まる（Shell・Green Shell は出ない）。
- 使い方:
  - Mushroom: まっすぐな道に来たら使う。
  - Banana: ぶら下げておき、後ろ 20m 以内に車が来たら置く。来なければ8秒後に置く。
  - Star・Lightning: 取ってから1〜3秒で使う。
- 取ってから使うまで、いつも0.5秒以上あける。人のプレイヤーをわざとねらわない。
- CPU も、人が投げた甲羅には当たって吹き飛ぶ。

## 11. 画面と音

- 上の真ん中にアイテムの枠。ルーレットの間は絵がくるくる変わり、決まったらそのアイテムの絵。
- 回している緑の甲羅の数は出さない（カートを見れば分かる）。
- 入れ替わりの残り秒数は出さない。バナナの皮が画面を横切る演出もなし（2026-10-22 のユーザー依頼）。
- 音:
  - 爆発: `sounds/Explosion04-1(Short).mp3`（ユーザーが用意）
  - 稲妻: `sounds/Thunder-Synthetic01-1.mp3`（ユーザーが用意）
  - ゲームの中で作る音: ルーレットのカラカラ、決まったときのピンピンピン、甲羅を出す音、キノコのしゅいーん、バナナを踏んだ音、Star のメロディ（本人だけ）
- 遊んでみて、そのつど直す。

## 12. ファイル構成

- `src/game/itemOdds.js`: 出やすさの表（人・CPU）と、順位からアイテムを決める関数。
- `src/game/itemBoxes.js`: コースごとの箱の列の場所。取ったら消えて2秒で戻る。
- `src/game/items.js`: アイテム枠・ルーレット・使ったときの効果（Mushroom・Star・Lightning の時間、バナナ、回る緑の甲羅、守り）。
- `src/game/shells.js`: 飛んでいる甲羅（赤は追いかける、緑はまっすぐ・はね返る、ジャンプ台・自動の区間で消える、当たり）。
- `src/game/kart.js`（今あるもの）: 吹き飛ぶスピン、Star の速さ、左右の入れ替え。
- `src/game/cpu.js`（今あるもの）: CPU がアイテムを使う判断。
- `src/render/items.js`: 「?」の箱、バナナ、甲羅、回る甲羅、Star の虹色、爆発の光と煙、稲妻。
- `src/hud.js`（今あるもの）: アイテムの枠とルーレット、画面の端の黄色い光、白い光。
- `src/audio/`（今あるもの）: アイテムの音。

## 13. 作る順番

1. 箱、アイテム枠とルーレット、Mushroom

3. 吹き飛ぶスピン、赤・緑の甲羅、守り
4. Star・Lightning
5. CPU のアイテム、音、仕上げ（5コースすべてで確かめる）

## 14. 確かめ方

- 自動テスト（`node --test`）:
  - 出やすさの表（各行の合計が100、行の選び方、Lightning が下半分だけ、CPU に甲羅が出ない）
  - 箱が消えて2秒で戻る、持っているときは何ももらえない
  - ITEM ボタンの順番（3.1）、緑の甲羅を回している間・バナナをぶら下げている間に次のアイテムを取れる
  - 赤の甲羅が相手に当たる、ジャンプ台で消える、障害物をすり抜ける
  - 緑の甲羅が柵ではね返り、4回目か5秒で消える
  - 守りが方向で決まる（3つ・2つ・1つ）、ぶら下げたバナナの守り
  - 入れ替わりの時間の延び方、Star の無敵
  - 吹き飛ぶスピンの時間と着地
  - CPU のアイテムの使い方
  - 全コースで、CPU 4台がアイテムありで最後まで走れる
- ブラウザで、5コースすべての箱の場所と見た目を確かめる。
- 公開して、タブレットで遊んでもらう。

## 15. 全体の設計書から変わる所

- 9.2: 入れ替わりの間に、真ん中の「⇄」と残り秒数は出さない。Banana を踏んだときにバナナの皮が横切る演出はなし（ぬかるみと同じ煙）。
- 9.3: 甲羅は障害物をすり抜ける。間の車・バナナ・Star の車の決まりはそのまま。
- 9.4: 柵ではね返るのは3回まで（4回目か5秒で消える）。守りは方向で決まる（8章）。後ろには投げない。
- 9.5: 吹き飛ぶ高さ・時間・回る回数を決めた（7章）。
- 9.6: 順位ごとの表を決めた（5章）。Lightning は「下から3番目まで」ではなく、「下半分の順位だけ 5%」。CPU には Shell・Green Shell が出ない。
- 新しく足す: バナナを後ろにぶら下げる（4.2）、緑の甲羅を回している間・バナナをぶら下げている間は次のアイテムを取れる（3章）。
