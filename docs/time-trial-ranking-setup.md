# TIME TRIAL のみんなの記録の設定（KENTA さんの作業・10分くらい）

ゲーム: Super Kyugo & Soki Kart

TIME TRIAL のタイムを、どの端末で走っても1つにまとめて、ゲームの中に出すための設定です。
Super Kyugo＆Soki Brothers の「みんなのランキング」と同じしくみで、記録をしまっておく「倉庫」として KENTA さんの Google スプレッドシートを使います（Brothers のスプレッドシートとは別に作ります）。遊ぶ人がスプレッドシートを見ることはありません。

パソコンのブラウザ（Chrome）で、ふだん使っている Google アカウントにログインした状態で進めてください。

## 1. スプレッドシートを作る

1. https://sheets.new を開く（新しいスプレッドシートができる）
2. 左上の「無題のスプレッドシート」を押して、名前を「カート タイムトライアル」にする

## 2. プログラムを貼る

1. 上のメニューの「拡張機能」→「Apps Script」を押す（新しいタブが開く）
2. 左上の「無題のプロジェクト」を押して、名前を「カート タイムトライアル」にする
3. 真ん中に `function myFunction() { ... }` と書いてあるので、全部消す
4. このフォルダの [apps-script/Code.gs](../apps-script/Code.gs) の中身を全部コピーして、貼り付ける
5. 上の「💾（プロジェクトを保存）」を押す

## 3. ウェブアプリとして公開する

1. 右上の青い「デプロイ」→「新しいデプロイ」を押す
2. 「種類の選択」の歯車 → 「ウェブアプリ」を選ぶ
3. 次のように設定する
   - 説明: タイムトライアル（なんでもよい）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」を押す
5. 「アクセスを承認」→ 自分の Google アカウントを選ぶ
6. 「Google はこのアプリを確認していません」と出たら、左下の「詳細」→「カート タイムトライアル（安全ではないページ）に移動」→「許可」
   - 自分で作ったプログラムなので、このように出るのはふつうです
   - このプログラムができるのは、このスプレッドシートに記録を書くこと・読むことだけです
7. 「ウェブアプリ」の URL（`https://script.google.com/macros/s/……/exec`）が出るので、「コピー」を押す

## 4. URL を Claude に伝える

コピーした URL を、チャットに貼ってください。ゲーム（`src/config.js` の `TIMES_URL`）に書き込んで公開します。

- この URL は、ゲームのプログラムの中に書かれます。ゲームの URL を知っている人なら、調べれば見つけられます。
- 知らない人に教えないでください（ゲームの URL と同じ扱い）。

## そのあと

- **記録を見る・直す**: スプレッドシートの「times」というシートに、1行1記録で入ります（最初の記録が届いたときにシートができます）。
  - 列: id（記録の番号）、course（コース）、name（名前）、character（kyugo / soki）、time（スタートからゴールまでの秒）、date（日付）、received（届いた時刻）
  - うその記録やいたずらは、その行を右クリック →「行を削除」で消せます。ゲームの記録からも消えます。
  - 全部消したいときは、2行目から下を全部消します（1行目の見出しは残す）。
- **ゲームに出るもの**: コースごとに速い順の上位10人。コース選びのボタンに1位（タイム・名前・キャラ名）、ゴールのあとに上位10位（日付・名前・キャラ名・タイム）。
- **電波がないとき**: その端末で前に受け取った記録を出します。走った記録は、つながったときに送ります。
- **手元の確かめ**（パソコンの localhost で開いたとき）: 記録は送りません。
- **お金**: かかりません（Google の無料の範囲で、家族で遊ぶ分には十分です）。

## Code.gs を直したとき（ふつうは不要）

「デプロイ」→「デプロイを管理」→ 鉛筆のマーク →「バージョン」を「新バージョン」にして「デプロイ」。URL は変わりません。
